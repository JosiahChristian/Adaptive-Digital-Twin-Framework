\# Experiment 018 — Explicit Mismatch Classification



\## Objective



Evaluate whether interpretable residual, temporal, and adaptation-response

features can be combined into an explicit mismatch-attribution mechanism.



The objective is not merely to detect that prediction disagreement exists, but

to infer the most likely physical source of that disagreement.



The candidate mismatch classes are:



1\. measurement noise,

2\. process disturbance,

3\. parameter mismatch,

4\. structural change.



\---



\## Attribution Features



The classifier combines three feature families.



\### Residual Features



These describe overall prediction disagreement:



\- mean absolute innovation,

\- mean normalized innovation squared,

\- longest run of NIS above one,

\- innovation lag-one autocorrelation.



\### Temporal Features



These describe how disagreement evolves around the event window:



\- event-minus-pre NIS change,

\- event maximum NIS,

\- recovery ratio,

\- event autocorrelation change.



\### Adaptation Features



These describe how the digital twin modifies its internal model:



\- persistent post-event parameter shift,

\- post-event cumulative parameter adaptation.



The combined feature representation is



\\\[

\\mathbf{f}

=

\[

\\mathbf{f}\_{residual},

\\mathbf{f}\_{temporal},

\\mathbf{f}\_{adaptation}

].

\\]



The mismatch estimate is then



\\\[

\\hat{z}

=

\\Psi(\\mathbf{f}).

\\]



\---



\## Interpretable Attribution Logic



The classifier uses physically motivated rules rather than a black-box

statistical model.



\### Measurement Noise



Expected characteristics include:



\- relatively large innovation magnitude,

\- weak temporal correlation,

\- limited persistence,

\- no strong event-centered model shift.



\### Process Disturbance



Expected characteristics include:



\- large event-centered NIS rise,

\- large event maximum,

\- rapid residual recovery,

\- little persistent parameter shift.



\### Parameter Mismatch



Expected characteristics include:



\- long periods of NIS inconsistency,

\- strong innovation autocorrelation,

\- high trajectory-wide mismatch,

\- no discrete step-50 event.



\### Structural Change



Expected characteristics include:



\- event-centered residual change,

\- significant persistent parameter shift,

\- continued post-event parameter adaptation.



Each class receives an interpretable attribution score, and the predicted class

is the class with the highest score.



The classification margin is defined as



\\\[

m

=

s\_{(1)}

\-

s\_{(2)},

\\]



where \\(s\_{(1)}\\) and \\(s\_{(2)}\\) are the largest and second-largest attribution

scores.



Small margins indicate ambiguous classifications.



\---



\## Dataset



The classifier was evaluated on:



\\\[

400

\\]



trajectories.



Each class contributed:



\\\[

100

\\]



stochastic realizations.



The feature datasets were generated by Experiments 015–017.



\---



\## Overall Accuracy



The classifier correctly attributed:



\\\[

390

\\]



of:



\\\[

400

\\]



trajectories.



Therefore,



\\\[

\\boxed{

\\mathrm{Accuracy}

=

97.5\\%

}

\\]



under the tested scalar conditions.



\---



\## Per-Class Accuracy



| Class | Correct | Total | Accuracy |

|---|---:|---:|---:|

| Measurement noise | 97 | 100 | 97% |

| Process disturbance | 93 | 100 | 93% |

| Parameter mismatch | 100 | 100 | 100% |

| Structural change | 100 | 100 | 100% |



Parameter mismatch and structural change were perfectly separated in this

dataset.



Process disturbance was the most difficult class.



\---



\## Confusion Analysis



The ten misclassifications were:



\### Measurement Noise



Three measurement-noise trajectories were misclassified:



\- two as process disturbance,

\- one as parameter mismatch.



\### Process Disturbance



Seven process-disturbance trajectories were misclassified:



\- four as parameter mismatch,

\- three as structural change.



No parameter-mismatch or structural-change trajectories were misclassified.



\---



\## Ambiguous Cases



Several errors occurred with extremely small classification margins.



For example, one process-disturbance trajectory was classified as structural

change with margin:



\\\[

m

\\approx

0.0003.

\\]



Another process-disturbance trajectory was classified as parameter mismatch

with margin:



\\\[

m

\\approx

0.0134.

\\]



These cases indicate that the observed feature signatures were nearly equally

compatible with multiple causal explanations.



This is an important result because it suggests that attribution should not

always be represented as a hard categorical decision.



\---



\## Interpretation



The experiment demonstrates that mismatch causes can be distinguished using

interpretable evidence derived from both system disagreement and digital-twin

adaptation.



The strongest attribution principle is:



\\\[

\\boxed{

\\text{cause}

\\neq

\\text{residual magnitude alone}

}

\\]



Instead,



\\\[

\\text{cause}

=

f(

\\text{magnitude},

\\text{persistence},

\\text{temporal response},

\\text{model adaptation}

).

\\]



Parameter mismatch is identified primarily through persistent correlated

residual behavior.



Structural change is identified primarily through sustained internal parameter

revision.



Measurement noise is characterized by relatively large but weakly persistent

residuals.



Process disturbances are characterized by strong transient event responses,

although sufficiently unusual disturbances can resemble parameter or

structural mismatch.



\---



\## Importance of Adaptation History



A major result from Experiment 017 carries directly into the classifier.



Process disturbance and structural change both return to approximately

consistent post-event NIS.



However, their internal model histories differ substantially.



Process disturbance produces:



\\\[

\\Delta \\hat{a}\_{post}

\\approx

0,

\\]



while structural change produces a persistent model revision:



\\\[

\\Delta \\hat{a}\_{post}

\\ll

0\.

\\]



Therefore, restored consistency does not erase information about what happened.



The twin's own adaptation trajectory becomes part of the diagnostic evidence.



\---



\## Classification Confidence



The classification margin provides a first approximation of attribution

confidence.



Large margin:



\\\[

m \\gg 0

\\]



indicates one explanation strongly dominates.



Small margin:



\\\[

m \\approx 0

\\]



indicates competing explanations remain plausible.



This suggests a future probabilistic architecture in which the twin represents



\\\[

P(z=j\\mid\\mathcal{I}\_k)

\\]



rather than forcing every mismatch into one deterministic class.



\---



\## Limitations



The attribution rules were constructed using the same experimental family from

which the characteristic signatures were discovered.



Therefore, the 97.5% accuracy should not be interpreted as out-of-distribution

generalization performance.



The current system also uses:



\- a scalar linear dynamical model,

\- fixed event timing,

\- fixed structural-change magnitude,

\- fixed disturbance magnitude,

\- fixed noise models,

\- and hand-designed score weights.



The classifier must therefore be validated under broader operating conditions

before any general attribution claim is justified.



\---



\## Conclusion



Experiment 018 demonstrates that physically interpretable mismatch attribution

is feasible in the current adaptive digital-twin framework.



Combining residual statistics, temporal event structure, and internal

adaptation behavior produced 97.5% classification accuracy across four mismatch

classes.



The remaining errors were concentrated in process-disturbance trajectories,

where transient events sometimes resembled persistent model mismatch or

structural change.



This motivates two future developments:



1\. explicit attribution confidence or ambiguity handling, and

2\. robustness testing under unseen mismatch magnitudes and operating

&#x20;  conditions.

Principal Result — Experiment 049. Learned memory-release control reduced intermediate-horizon epistemic error relative to fixed hysteretic release (MAE 0.0564 vs. 0.0573 at t=70, and 0.0576 vs. 0.0582 at t=80), but increased release frequency tenfold (0.175 vs. 0.0175 releases per trajectory) and increased mean memory-state transitions from 0.5125 to 0.7175. At t=100, learned release became slightly inferior to fixed release (0.0591 vs. 0.0586). Release-decision accuracy remained approximately 65.5–69.5%. These results indicate that independently learned release can reduce memory inertia, but insufficiently reliable instantaneous release decisions introduce premature forgetting and additional switching. Memory release therefore requires temporal confirmation rather than snapshot classification alone.
